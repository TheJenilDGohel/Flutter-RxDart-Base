# Repository Recipes

Production-ready repository patterns for the Flutter-RxDart-Base architecture.
Every repository is **transport only**: calls `ApiBaseHelper`, returns raw `Map<String, dynamic>`, accepts `CancelToken? cancelToken`, and never calls `fromJson`.

---

## Recipe A: Standard Paginated List & Detail Fetch

The default pattern generated by `mason make bloc`. Accepts `page`, `limit`, and forwards `CancelToken`.

```dart
import 'package:dio/dio.dart';

class OrdersRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> fetchOrders({
    required int page,
    int limit = 20,
    CancelToken? cancelToken,
  }) {
    return _api.get(
      ApiConstants.ordersEndpoint,
      queryParameters: {'page': page, 'limit': limit},
      cancelToken: cancelToken,
    );
  }

  Future<Map<String, dynamic>> fetchOrderDetail({
    required String id,
    CancelToken? cancelToken,
  }) {
    return _api.get(
      ApiConstants.orderEndpoint(id),
      cancelToken: cancelToken,
    );
  }
}
```

## Recipe B: Sanitized Filter & Query Parameters

Prevents dirty URLs (`?search=&status=&tag=`) by omitting empty, blank, or null parameters before sending to `ApiBaseHelper`.

```dart
import 'package:dio/dio.dart';

class InquiriesRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> getInquiries({
    required int page,
    required int limit,
    String? search,
    String? status,
    String? priority,
    DateTime? fromDate,
    CancelToken? cancelToken,
  }) {
    return _api.get(
      ApiConstants.inquiriesEndpoint,
      queryParameters: {
        'page': page,
        'limit': limit,
        ..._sanitizeFilters(
          search: search,
          status: status,
          priority: priority,
          fromDate: fromDate,
        ),
      },
      cancelToken: cancelToken,
    );
  }

  Map<String, dynamic> _sanitizeFilters({
    String? search,
    String? status,
    String? priority,
    DateTime? fromDate,
  }) {
    final params = <String, dynamic>{};
    if (search != null && search.trim().isNotEmpty) {
      params['search'] = search.trim();
    }
    if (status != null && status.isNotEmpty) {
      params['status'] = status;
    }
    if (priority != null && priority.isNotEmpty) {
      params['priority'] = priority;
    }
    if (fromDate != null) {
      params['fromDate'] = fromDate.toIso8601String().split('T').first;
    }
    return params;
  }
}
```

## Recipe C: Capability Composition with Mixins (Rule 1)

Never extend another feature's repository (`class InquiriesRepo extends AllAgentsRepo` is forbidden because inheritance leaks unrelated or sensitive endpoints). Compose shared capabilities with `mixin`.

```dart
import 'package:dio/dio.dart';

/// Shared capability: fetching agent options for filter dropdowns.
mixin AgentsDropdownMixin {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> fetchAgentOptions({
    CancelToken? cancelToken,
  }) {
    return _api.get(
      ApiConstants.agentsDropdownEndpoint,
      cancelToken: cancelToken,
    );
  }
}

/// Feature repository using the shared mixin capability.
class InquiriesRepo with AgentsDropdownMixin {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> fetchInquiries({CancelToken? cancelToken}) {
    return _api.get(ApiConstants.inquiriesEndpoint, cancelToken: cancelToken);
  }
}
```

## Recipe D: Multipart Form-Data & File Upload

Uploading images, documents, or visiting cards with progress tracking and extended transfer timeouts.

```dart
import 'dart:io';
import 'package:dio/dio.dart';

class InquiryUploadRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> submitInquiryWithCard({
    required Map<String, dynamic> fields,
    File? visitingCard,
    void Function(int sent, int total)? onProgress,
    CancelToken? cancelToken,
  }) async {
    final formDataMap = Map<String, dynamic>.from(fields);

    if (visitingCard != null && visitingCard.existsSync()) {
      formDataMap['visiting_card'] = await MultipartFile.fromFile(
        visitingCard.path,
        filename: visitingCard.path.split(Platform.pathSeparator).last,
      );
    }

    return _api.postFormData(
      ApiConstants.inquiriesEndpoint,
      data: formDataMap,
      onSendProgress: onProgress,
      options: Options(
        sendTimeout: const Duration(seconds: 120),
      ),
      cancelToken: cancelToken,
    );
  }
}
```

## Recipe E: Bulk / Unpaged / Long-Running Fetch (`all=true`)

Bulk exports, reports, or full tenant synchronization where server response times exceed standard 30s timeouts.

```dart
import 'package:dio/dio.dart';

class ReportsRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> fetchAllReportRows({
    required Map<String, dynamic> filters,
    CancelToken? cancelToken,
  }) {
    return _api.get(
      ApiConstants.reportsEndpoint,
      queryParameters: {
        'all': 'true',
        ...filters,
      },
      options: Options(
        receiveTimeout: const Duration(seconds: 180),
      ),
      cancelToken: cancelToken,
    );
  }
}
```

## Recipe F: Binary / Document Download (PDF, CSV, Invoices)

Downloading binary files or stream bytes with cancellation and progress reporting.

```dart
import 'package:dio/dio.dart';

class InvoiceDownloadRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<List<int>> downloadInvoicePdf({
    required String invoiceId,
    void Function(int received, int total)? onProgress,
    CancelToken? cancelToken,
  }) async {
    final response = await _api.dio.get<List<int>>(
      ApiConstants.invoicePdfEndpoint(invoiceId),
      options: Options(
        responseType: ResponseType.bytes,
      ),
      onReceiveProgress: onProgress,
      cancelToken: cancelToken,
    );
    return response.data ?? const [];
  }
}
```

## Recipe G: Transparent Cache-Aside / Storage Stash

Stashing raw response data in local database or cache before returning, without breaking repository transport boundaries.

```dart
import 'package:dio/dio.dart';

class ProfileRepo {
  final ApiBaseHelper _api = ApiBaseHelper.instance;

  Future<Map<String, dynamic>> fetchProfile({
    Future<void> Function(Map<String, dynamic> raw)? onCacheStash,
    CancelToken? cancelToken,
  }) async {
    final json = await _api.get(
      ApiConstants.profileEndpoint,
      cancelToken: cancelToken,
    );
    if (onCacheStash != null) {
      await onCacheStash(json);
    }
    return json;
  }
}
```

## Recipe H: Silent Token Refresh Flow & Queued Request Replay

For applications with short-lived access tokens (e.g., 15-minute expiration) and a refresh token. When a 401 occurs, this handler pauses subsequent requests, requests a fresh token, updates `AppStore`, and replays the original request before `ErrorMappingInterceptor` triggers a logout.

```dart
import 'dart:async';
import 'package:dio/dio.dart';

class SessionRefreshHandler {
  SessionRefreshHandler._();
  static final SessionRefreshHandler instance = SessionRefreshHandler._();

  Completer<String?>? _refreshCompleter;

  /// Checks if a 401 response can be silently refreshed, updating the store
  /// and returning the new token, or null if refresh fails.
  Future<String?> refreshToken({
    required Dio dio,
    required String refreshToken,
  }) async {
    // If a refresh is already in flight, await that same future (mutex lock).
    if (_refreshCompleter != null) {
      return _refreshCompleter!.future;
    }

    _refreshCompleter = Completer<String?>();
    try {
      final response = await dio.post<Map<String, dynamic>>(
        ApiConstants.refreshTokenEndpoint,
        data: {'refresh_token': refreshToken},
        options: Options(headers: {'Requires-Token': 'false'}),
      );

      final data = response.data;
      final newToken = data?['access_token']?.toString();
      if (newToken != null && newToken.isNotEmpty) {
        AppStore.dispatch(SetAuthTokenAction(newToken));
        _refreshCompleter!.complete(newToken);
        return newToken;
      }
      _refreshCompleter!.complete(null);
      return null;
    } catch (e) {
      _refreshCompleter!.complete(null);
      return null;
    } finally {
      _refreshCompleter = null;
    }
  }
}
```
